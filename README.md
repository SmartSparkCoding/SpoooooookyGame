# SpoooooookyGame

## General Info

Get ready to be scared by my SPOOOOOOOKY game! (Perfect for halloween lol!) 

This game has been made with p5.js, using the GhostShip guide from Hack Club! 

## How to Play

The game is quite simple! Simply click the ghosts, to gain a point, click somewhere among the stars, lose a point! 
The stars generate over time, getting more and more in your way, making it harder and harder to see the ghosts! 
You start off with 0 points, and only 20 seconds to gain points! 
Try to get the highest score possible! If you get over 40 points, please dm me on slack, I would LOVE to see! 
This game hasn't been tested on mobile, however, on desktop all you have to do is click the ghosts (and click to start/restart)

## Extra Features

1. Generating stars over time
2. Extra info (2 lines) on the start screen
3. Adjustments to text on the Game Over screen to be more spooky!
4. More elongated ghosts!
5. Slowing down the spawning of the ghosts.
6. Less time to complete the game.
7. Loss of a point if you mis-click anywhere that ISN'T a ghost.
8. Mouth added to the ghost!
